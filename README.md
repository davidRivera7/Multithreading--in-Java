# 🧵 Ejercicios de Concurrencia e Hilos en Java

Repositorio dedicado al estudio, diseño e implementación de **concurrencia en Java**.

---

## 📂 Estructura de Ejercicios y Bitácora de Aprendizajes

Este repositorio documenta un proceso de aprendizaje incremental.

* **1. `oddEvenPrinter`** (Impresor Alterno de Pares e Impares)
* **2. `print_1_n_using_m_threads`** (Impresión Secuencial con $M$ Hilos)
* **3. `pingPongSemaphores`** (Impresión Secuencial Ping-Pong con Semaphores)
* **4. `A_B_C_Semaphores`** (Impresión Secuencial ABC utilizando semaphores y 3 Threads)
* **5. `A_B_C_wait_notify_n_times`** (Impresión Secuencial ABC utilizando wait(), notify() y 3 Threads)
* **6. `A_B_C_wait_notify_3n_times`** 
* **7. `A_B_C_wait_notify_3n_times_best`**
